# Short Cfx update description — v1.0.2

FINAN Notify v1.0.2 fixes the opaque NUI background, adds French and Spanish language support, and introduces reliable English fallback for missing translations. The Cfx upload archive is now cleaner and contains only the files required by server owners. Existing exports and events remain unchanged.

# Updated product description

FINAN Notify is a modern, lightweight and framework-independent notification system for FiveM.

Designed for performance, compatibility and easy integration.

## Features

- Standalone support
- ESX compatible
- QBCore compatible
- Qbox compatible
- Modern responsive UI with transparent NUI background
- Success, error, info and warning notifications
- English, German, French and Spanish default notification titles
- English fallback for missing translations
- Developer-friendly client and server exports
- Configurable positions, duration and bounded queue handling
- Event-driven operation with no permanent polling loops

Custom titles and messages are supplied by your server resources and are not automatically translated.

Built with care by FINAN STUDIOS.
